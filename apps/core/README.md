# Core App

## Purpose
The core app provides foundational functionality and shared resources for the Family Tree Generator application.

## Key Components

### Templates
- `base.html`: Base template with common layout and assets
- Shared template components

### Static Files
- Core CSS and JavaScript
- Shared images and assets
- Favicon and branding elements

### Utilities
- Common template tags and filters
- Shared context processors
- Base view mixins

## Usage
This app is automatically included in all other apps through template inheritance and static file references.
